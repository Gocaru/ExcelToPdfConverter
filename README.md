# 📊 Excel to PDF Converter

Aplicação console em C# para converter ficheiros Excel (.xlsx) em PDFs profissionalmente formatados.

## 🛠️ Tecnologias
- C# / .NET 8
- ClosedXML (leitura Excel)
- QuestPDF (geração PDF)

## 🚀 Como Usar
```bash
ExcelToPdfConverter.exe ficheiro.xlsx saida.pdf
```

## 📦 Instalação
1. Clonar repositório
2. Abrir no Visual Studio 2022
3. Restaurar NuGet packages
4. Compilar e executar

## 📋 Requisitos
- .NET 8 SDK
- Visual Studio 2022

## 🎯 Funcionalidades
- Leitura de ficheiros Excel (.xlsx)
- Geração de PDF em formato landscape
- Tabela formatada com cores alternadas
- Cabeçalhos estilizados
